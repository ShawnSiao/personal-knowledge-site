# 实践知识库

这里整理能够重复使用的工程经验、产品方法、内容规范和验证框架。

知识首先服务于检索、关联和继续工作，也保留适合人阅读的文章形式。公开内容来自一个独立的私有知识库，只有经过审核的白名单页面才会进入本站。

## 从这里开始

- [[articles/publishable-agent-knowledge-base|建立一个可出版的 Agent 知识库]]
- [[articles/personal-knowledge-content-map|个人项目应该沉淀成哪些知识]]

## 内容原则

- 来源与结论分开记录。
- 已确认事实、个人经验、分析推断和待验证信息使用不同边界。
- 公开站不复制私有资料库，也不暴露本地路径、账号、凭据或原始工作记录。
- 文章以解决一个具体问题为单位，持续修订，不追求一次生成后永久不变。

本站内容是个人实践总结，不代表第三方项目或机构立场。
