# 程序员的AI开发第一课

[[learning/ai/foundations|大模型入门与提示词]] · 主线

## 课程内容与定位

本地资料涉及模型基础、提示词、模型调用、RAG 与 Agent 的整体关系。本站依据目录和章节元数据归类，以下学习安排与练习为原创整理，不是课程讲义转载，也不表示已经完成全部课程或实践。

## 章节学习安排

### 第 01–06 讲：模型概念、提示和 API 调用

完成一次能处理错误的调用，说明上下文与输出各自的作用。

### 第 07–14 讲：框架抽象、RAG 和 Agent

先把处理流程画出来，再选择框架实现。

### 第 15–21 讲：记忆、缓存、接入与模型定制

围绕实际问题选学，记录缓存失效与数据边界。

## 配套练习

完成一个有输出校验的文本整理器，再选择 RAG 或 Agent 分支。

练习记录至少包含输入样例、处理过程、实际结果、失败原因和下一步修改。没有运行过的内容保留为学习计划，不写成实践结论。

## 完成检查

- 能用自己的话解释本课所选主题，指出适用条件。
- 保留一次成功与一次失败的具体输入和结果。
- 按[[learning/ai/foundations|大模型入门与提示词专题]]的验收要求检查练习。
