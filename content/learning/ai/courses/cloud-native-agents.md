# AI重塑云原生应用开发实战

[[learning/ai/agents|Agent、MCP 与运行控制]] · 进阶

## 课程内容与定位

本地资料涉及工具调用、Go Agent、集群运维工具与 AI 网关。本站依据目录和章节元数据归类，以下学习安排与练习为原创整理，不是课程讲义转载，也不表示已经完成全部课程或实践。

## 章节学习安排

### 第 01–04 讲：工具调用与 Agent 基础

完成一个只读工具调用例子。

### 第 05–12 讲：集群资源与诊断工具

使用模拟或隔离环境，记录查询范围。

### 第 13–17 讲：平台与 API Agent

比较平台提供的能力和需要自行实现的控制。

### 第 18–26 讲：网关与扩展

围绕具体请求记录权限、路由和错误处理。

## 配套练习

用模拟集群资料实现只读诊断，任何变更都先产生待审批计划。

练习记录至少包含输入样例、处理过程、实际结果、失败原因和下一步修改。没有运行过的内容保留为学习计划，不写成实践结论。

## 完成检查
